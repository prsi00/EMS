# Employee Management System (EMS)

A full-stack, production-ready Employee Management System built with React, Tailwind CSS, and Supabase. Features include global authentication, role-based dashboards (Admin/Employee), attendance tracking, monthly reports, and bulk salary processing.

## Tech Stack
- **Frontend Framework:** React (via Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Routing:** React Router DOM
- **Backend/Database:** Supabase (PostgreSQL)

---

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd ems
```

### 2. Install Dependencies

Navigate into the React application directory and install the required npm packages.

```bash
cd ems-app
npm install
```

### 3. Setup Supabase Database Schema

Create a new project @ Supabase

```sql
-- -- 1. Create Employees Table
CREATE TABLE employees (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  name TEXT NOT NULL,
  phone TEXT UNIQUE NOT NULL, -- Unique constraint for login checks
  dob DATE NOT NULL,
  email TEXT,
  role TEXT DEFAULT 'employee'
);

-- 2. Create Attendance Table
CREATE TABLE attendance (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  employee_id UUID REFERENCES employees(id) ON DELETE CASCADE,
  date DATE NOT NULL DEFAULT CURRENT_DATE,
  status TEXT CHECK (status IN ('Present', 'Absent', 'Leave')),
  UNIQUE(employee_id, date) -- CRITICAL: Allows upserting if a record for this employee/date already exists
);

-- 3. Create Salaries Table
CREATE TABLE salaries (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  employee_id UUID REFERENCES employees(id) ON DELETE CASCADE,
  month_year TEXT NOT NULL,
  amount NUMERIC NOT NULL,
  UNIQUE(employee_id, month_year) -- CRITICAL: Allows upserting if payroll for this month already exists
);

ALTER TABLE salaries
ADD COLUMN credited_date DATE;

```

To add an admin user, run the following SQL query:

```sql
INSERT INTO employees (name, phone, dob, role) 
VALUES ('Super Admin', '1234567890', '1990-01-01', 'admin');
``` 

### 4. Configure Environment Variables

Create a `.env` file in the root of the React application (`ems/ems-app/`) to securely store your Supabase connection keys.

```bash
# Inside ems/ems-app/
touch .env
```

Open the `.env` file and add the following variables. Replace the placeholder text with your actual Supabase URL and Anon Key.

```env
VITE_SUPABASE_URL=your_supabase_project_url_here
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key_here
```

### 5. Run the Local Development Server

Start the Vite development server.

```bash
npm run dev
```

The application will typically be accessible at `http://localhost:5173`. Open this URL in your browser to start using the system!
